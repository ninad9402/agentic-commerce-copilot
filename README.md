# 🚀 GrowthCopilot.ai — Autonomous Agentic Commerce Ecosystem

> **Autonomous AI Agent & Multi-Agent Swarm for High-Growth E-Commerce Brands**  
> Mines store data, clusters customer cohorts, detects checkout drop-offs, drafts high-converting multichannel assets, enforces margin guardrails, and learns continuously via closed-loop reinforcement.

---

## 🌟 Key Features

### 1. 📊 Visual Store Intelligence & Forecasting (Recharts)
- **Revenue Forecast Curve**: Interactive Area chart comparing organic baseline vs. agentic projections vs. realized revenue.
- **RFM Customer Matrix**: Customer cohort volume against average lifetime spend across VIP, Loyal, At-Risk, and Cart Abandoners.
- **Funnel Drop-off Analyzer**: Step-by-step conversion drop-off visualization highlighting checkout revenue leakages.

### 2. 🤖 Multi-Agent Swarm Collaboration Hub
- **4 Cooperating Autonomous Subagents**:
  - 🔍 **Data Miner Agent (Dr. Sarah Chen)**: Cohort clustering & session leakage extraction.
  - 🏷️ **Margin & Pricing Guardrail Agent (Elena Rostova)**: Preserves unit gross margins and enforces discount ceilings.
  - ✍️ **Creative Direct-Response Agent (Marcus Reed)**: Generates high-converting copywriting tailored to brand voice.
  - ⚡ **Integration & Dispatch Agent (Alex Vance)**: Packages production GraphQL mutations and REST API payloads.

### 3. 🧪 A/B Multi-Variant Experimentation Studio
- Side-by-side comparison of 3 strategic angles:
  - **Variant A (Urgency & Scarcity)**: Flash countdowns & low-stock alerts.
  - **Variant B (Social Proof & Trust)**: Verified 5-star customer reviews & risk-free guarantees.
  - **Variant C (VIP Exclusivity & Curiosity)**: Secret member perks & private discounts.

### 4. 🎛️ Interactive Strategy & ROI Simulator
- Real-time sliders for Audience Reach %, Promotional Discount %, Channel Mix (Email vs. SMS vs. WhatsApp), and Urgency Duration.
- Live recalculation of Gross Uplift, Net Margin, Recovered Orders, and Simulated ROAS.

### 5. 🔌 Live Integration Sandbox & Webhook Inspector
- Inspect mock API schemas and payloads:
  - **Shopify Admin GraphQL**: `discountCodeAppCreate` mutation.
  - **Stripe REST API**: `POST /v1/promotion_codes` payload.
  - **Klaviyo Track API**: Automated flow dispatch.
  - **WhatsApp Business Cloud API**: Interactive HSM template broadcast.
- Interactive **"Test Dispatch"** button with simulated HTTP 200 responses.

### 6. 🧠 Agent Long-Term Memory & Merchant Guardrails Studio
- Inspect empirical priors learned from past closed-loop campaigns.
- Dynamic weight adaptation trackers (+25% Cart Recovery, +18% VIP Retention).
- Custom Merchant Guardrails editor: add and toggle business constraints.

### 7. 🎨 Dynamic Brand Voice Selector
- Switch between 4 distinct brand voices:
  - ⚡ *Fast-Action Urgency*
  - 🎉 *Playful & Friendly*
  - 💎 *Luxury & Minimalist*
  - 🔬 *Performance & Analytical*

## 🛠️ Tech Stack
- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Vanilla CSS Glassmorphism
- **Charts & Data Visualization**: [Recharts](https://recharts.org/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Effects**: Canvas Confetti

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or [http://localhost:3001](http://localhost:3001)) in your browser.

### 3. Build for Production
```bash
npm run build
npm start
```
